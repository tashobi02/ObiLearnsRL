# LunarLander PPO

This folder keeps the original Hugging Face course notebook, its locally executed copy, and two reproducible PPO runs.

## Run the 200k-step workflow

From the `Unit 1` directory, activate the environment described in `requirements.txt`, then run:

```bash
python Notebook/scripts/train_ppo.py
xvfb-run -a python Notebook/scripts/evaluate_ppo.py
HF_TOKEN=hf_xxx xvfb-run -a python Notebook/scripts/package_to_hub.py
```

Training saves the final and best models in `Notebook/runs/200k/models/`, TensorBoard and evaluation logs in `Notebook/runs/200k/logs/`, and evaluation videos in `Notebook/runs/200k/videos/`.

The saved 200k model was evaluated over 10 deterministic episodes at `+75.20 ± 93.84` mean reward; the best checkpoint was recorded at 150k steps.

## Run the 1m-step experiment

```bash
python Notebook/scripts/train_ppo_1m.py
xvfb-run -a python Notebook/scripts/evaluate_ppo_1m.py
HF_TOKEN=hf_xxx xvfb-run -a python Notebook/scripts/package_to_hub_1m.py
```

Its models, logs, and videos are stored under `Notebook/runs/1m/`. The saved 1m run reached `+247.53 ± 23.41` mean reward in the 10-episode checkpoint evaluation at 1m steps.

## Notebooks

- `notebooks/unit1.ipynb` is the original course notebook.
- `notebooks/unit1_executed.ipynb` is its local adaptation with saved outputs.
- `scripts/preprocess_for_local.py` prepares the local copy; `scripts/execute_local.py` runs it using the active Python kernel.

The downloaded models and demo videos are kept as useful run outputs. Logs can be regenerated by training and evaluation.
