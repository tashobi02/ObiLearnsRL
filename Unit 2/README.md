# Unit 2 — Tabular Q-learning

This unit contains the original course notebook, a locally runnable version, one-million-step training runs for FrozenLake and Taxi, notes, and foundational papers.

## Contents

- [Notes](Notes/README.md) — Q-learning concepts and study notes.
- [Notebook](Notebook/README.md) — original and executed notebooks, scripts, models, and videos.
- [Papers](Papers/README.md) — local PDFs and a reading order.
- [requirements.txt](requirements.txt) — Python dependencies.

From this directory, install the dependencies with `python -m pip install -r requirements.txt`. The notebook uses Gymnasium RGB arrays and does not require a display server.
